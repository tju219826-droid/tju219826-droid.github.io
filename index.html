BEFORE YOU BEGIN

先留好回程的路

重装是替换系统，不是普通更新。无论使用 KiwiVM 面板还是 DD 写入镜像，磁盘上的数据都会被清除。

!
先备份，再操作

保存网站文件、数据库和配置，并确认备份可以用于恢复。可检查 KiwiVM 中的快照或自动备份选项；不要在尚未确认恢复方案时开始重装。

02 / KIWIVM

通过面板重装 Linux

以下搬瓦工控制面板教程按参考资料中的操作顺序整理。具体系统版本与界面选项以面板显示为准。

  1. 进入控制面板

    登录账户，在 Services → My Services 找到目标 VPS，进入 KiwiVM Control Panel。

  2. 停止 VPS

    在 Main Controls 查看状态；如果正在运行，点击 Stop，等待完全关机。

  3. 选择系统

    打开 Install new OS，从当前列表中选择需要的 Linux 发行版和版本，例如可用的 Ubuntu 或 Debian。

  4. 确认并重装

    再次确认备份和目标 VPS，阅读数据清除提示，勾选同意后点击 Reload。等待安装完成。

  5. 保存连接信息

    记录面板提供的新密码和 SSH 端口，并妥善保管；重连时使用当前显示的信息，不要假定端口仍是 22。

03 / CUSTOM IMAGE

DD 与自定义系统

DD 的思路是将完整系统镜像写入磁盘，可用于定制 Linux 或 Windows 等需求。它会覆盖原有系统，对镜像、引导和连接恢复都有更高要求。

01

准备基础系统

先通过 KiwiVM 安装一个可用的 Linux 系统，确认可以通过 SSH 连接。

02

写入可信镜像

通过 SSH 执行与目标镜像匹配、来源可信的写入流程。操作前核对目标磁盘；写入期间连接可能中断。

03

查看并加固

使用面板中的 VNC 查看启动状态。进入新系统后，及时更改镜像默认密码并检查网络设置。

参考资料也提到通过 Mount ISO 挂载可引导镜像安装系统。可用性和操作方式请以实际面板选项为准。本文不提供未经核实的脚本或镜像地址。

04 / AFTER INSTALLATION

重装后，检查这几项

如果远程连接失败，先从新系统的连接信息排查，再检查网络与安全设置。

  • SSH 端口在 KiwiVM 主页确认当前 SSH port，连接时使用该端口。
  • 账号与密码核对新系统提供的用户名和密码；自定义镜像应尽快修改默认密码。
  • 防火墙检查规则是否阻止了所需端口；必要时通过 VNC 查看系统状态。
  • 备份恢复确认系统可正常访问后，再按恢复方案还原文件、数据库及配置。

06 / FAQ

常见问题

重装之后数据还在吗？

面板重装和 DD 写入都会清除磁盘数据。开始前请先备份，并确认恢复方案。

重装会改变 IP 吗？

参考资料说明，重装系统或 DD 写入不会改变 VPS 的 IP；系统重装与更换 IP 是不同操作。

面板里没有需要的系统怎么办？

可以查看面板是否提供 ISO 挂载选项，或在可连接的基础系统上考虑 DD 写入可信镜像。请先确认兼容性和恢复方案。

为什么重装后 SSH 连不上？

先核对面板显示的 SSH 端口、新系统账号和密码，再检查防火墙；也可通过 VNC 查看系统状态。
